# От DOM/превью к исходнику компонента

## When to use

В чате есть DOM path, подсветка узла в превью или скрин без явного пути к файлу.

## Steps

1. Извлеки устойчивые подсказки: `data-testid`, `id`, уникальный текст, роль ARIA, имя кнопки.
2. Найди строку в коде (поиск по тексту или по классу, если он редкий и не из сгенерированного бандла).
3. Если классы утилитарные и общие — сузь по иерархии: родительский layout, карточка, страница.
4. Открой найденный компонент и подтверди соответствие дереву из снапшота.
5. Вноси правку в том компоненте или в дизайн-примитиве, который реально владеет разметкой.
6. Обнови превью и сверь визуально узел, который изначально выделяли.
7. При необходимости добавь/уточни доступность (подписи, `aria-*`) без изменения смысла задачи.
