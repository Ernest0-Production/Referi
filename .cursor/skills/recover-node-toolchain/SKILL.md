# Восстановление Node/npm окружения в проекте

## When to use

Команды `npm`/`node`/`tsc`/`next` не находятся, падают с неверной версией, `node_modules` повреждён, симлинки в `.bin` битые.

## Steps

1. Проверь текущий каталог (`pwd`) и что ты в корне репозитория с `package.json`.
2. Выясни ожидаемый менеджер версий Node (`.nvmrc`, `.node-version`, документация в README).
3. Активируй профиль (nvm/mise/volta) или используй явный путь к нужной версии Node.
4. Удали повреждённый `node_modules` и lock-совместимую переустановку (`npm ci` при наличии lock-файла).
5. Проверь, что `./node_modules/.bin/<инструмент>` существует и отвечает `--version`.
6. Повтори исходную команду из скриптов `package.json`, а не голый `npx` вне проекта.
7. Если CI/контейнер отличается от хоста — зафиксируй расхождение для пользователя без маскировки.
