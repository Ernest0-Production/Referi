# Introduction

Модерация споров и жалоб выполняется через **данные в Referi** (`ModeratorCase`, `AbuseReport`) и **админ-панель** (`/admin`, роутеры `moderation.*`). Отдельной серверной интеграции с мессенджерами нет.

Для **дополнительной связи** пользователя с командой модерации вне приложения используется **одна публичная ссылка**, задаваемая в окружении.

## Переменная окружения

| Переменная                           | Обязательная | Описание                                                                                                                                              |
| ------------------------------------ | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_MODERATION_CONTACT_URL` | Нет          | HTTPS- или другая ссылка на открытый контакт (например `https://t.me/username`). Встраивается в UI после отправки жалобы и в настройках, если задана. |

Ссылка попадает в клиентский бандл (`NEXT_PUBLIC_*`): не использовать для секретов.

## Поведение в UI

- После успешной отправки жалобы пользователю показывается подтверждение и опционально ссылка «Связаться с модерацией», если переменная задана.
- На странице настроек (`/dashboard/settings`) при заданной переменной отображается блок «Связь с модерацией».
