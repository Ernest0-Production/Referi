# Локализация UI (ru)

## Назначение

Все пользовательские строки интерфейса и серверных описаний платежей/валидации для русского языка собраны в модуле **`src/locales/`**. Сейчас поддерживается **одна локаль** (`ru`); переключение языков по URL или cookie не реализовано.

## Где править текст

- Корневой объект словаря: **`src/locales/ru/index.ts`** (собирает секции из `src/locales/ru/*.ts`).
- Секции по областям: `common.ts`, `site.ts`, `applications.ts`, `vacancies.ts` (в т.ч. подписи валют зарплаты `salaryCurrencyLabels`, формат «от/до» в `salaryRangeDisplay`), `dashboard.ts`, `admin.ts`, `payAuth.ts`, `server.ts`.

Импорт в коде:

```ts
import { ru } from "@/locales";
// пример: ru.vacancies.catalog.notFoundTitle
```

Серверные роутеры и воркеры импортируют те же ключи из `ru.server.*`, чтобы описания платежей и сообщения Zod совпадали с продуктовыми формулировками.

## Расширение на другие языки

Потребуется: второй файл словаря, выбор активной локали (например константа или конфиг), и замена прямых обращений `ru` на функцию/контекст выбора словаря. Текущая структура секций остаётся шаблоном для новых локалей.
