# UI shell (навигация и страницы)

Нормативное описание оболочки интерфейса после выравнивания с публичным каталогом рефералок.

## Компоненты шапки

| Область | Компонент | Файл |
|--------|-----------|------|
| Публичные страницы (каталог, деталь рефералки, login, регистрация, mock-оплата, pay без вложенного layout) | `PublicHeaderNav` | [`src/components/PublicHeaderNav.tsx`](../src/components/PublicHeaderNav.tsx) |
| Кабинет (плоские URL: `/settings`, `/profile`, `/applications`, `/vacancy`, `/attempts` и вложенные; группа маршрутов `(account)`) | `DashboardHeaderNav` + layout | [`src/components/DashboardHeaderNav.tsx`](../src/components/DashboardHeaderNav.tsx), [`src/app/(account)/layout.tsx`](../src/app/%28account%29/layout.tsx) |
| Модерация `/admin/*` | `AdminHeaderNav` + layout | [`src/components/AdminHeaderNav.tsx`](../src/components/AdminHeaderNav.tsx), [`src/app/admin/layout.tsx`](../src/app/admin/layout.tsx) |

Правило: **первичная навигация задаётся в `layout.tsx` соответствующего сегмента**, а не дублируется в каждой `page.tsx`. Ссылка бренда слева (квадрат с «R» и текст **Referi**) во всех трёх шапках показывает **и логотип, и название** на всех ширинах viewport (без скрытия текста на узких экранах); переход в **каталог рефералок** — по этой ссылке на главную (`/`). Отдельного выпадающего меню для каталога в шапке нет. В `PublicHeaderNav` и `DashboardHeaderNav` **нет** горизонтального ряда кнопок «Запросы» / «Моя рефералка» и **нет** отдельной кнопки «Настройки» рядом с брендом; в меню профиля по аватару для авторизованного пользователя — **«Настройки»** (`/settings`) и выход. Отдельного корневого URL кабинета нет: защищённые страницы живут по перечисленным путям. В шапках кабинета и админки доступны переключатель темы (`ThemeToggle`) и выход из аккаунта (через меню профиля). Аватар в шапке: фото профиля GitHub (`session.user.image` / запасной URL по логину), при отсутствии или ошибке загрузки — инициалы в `AvatarFallback`.

## Поверхность страницы и токены

Фон «страницы приложения» (в т.ч. каталог и кабинет) задаётся CSS-переменной **`--app-page-surface`** в [`src/app/globals.css`](../src/app/globals.css). Акцент поиска в шапке: **`--app-search-accent-*`**. Токены **`--app-nav-cta-*`** используются в панели фильтров каталога (в т.ч. основная кнопка сохранения набора), не в шапке.

Тема: `next-themes` в корневом [`src/app/layout.tsx`](../src/app/layout.tsx); семантические классы Tailwind (`bg-background`, `text-muted-foreground`, `border-border`, компоненты shadcn) предпочтительнее сырых `gray-*`.

## Основная колонка и хлебные крошки

Горизонтальные отступы основной колонки с контентом и **`AppNavBreadcrumb`** унифицированы: **`PAGE_COLUMN_CLASS`** в [`src/lib/pageContentShell.ts`](../src/lib/pageContentShell.ts) (**`max-w-2xl`**, **`gap-8`**, **`p-6 md:p-8`**) — как у раздела «Настройки», чтобы крошки и карточки на публичной рефералке и в кабинете стояли на одной вертикали.

Цепочка **`AppNavBreadcrumb`** в режиме **stacked** (по умолчанию, кроме явного `variant="static"`) строится **клиентским стеком** в [`NavBreadcrumbStack.tsx`](../src/components/navigation/NavBreadcrumbStack.tsx): каждая страница с крошками подключает канонический **seed** через **`BreadcrumbSeedPort`** (данные сегментов по-прежнему задаются в [`navBreadcrumbTrail.ts`](../src/lib/navBreadcrumbTrail.ts) на сервере). При переходе **вперёд** seed **сливается** со стеком ([`navBreadcrumbMerge.ts`](../src/lib/navBreadcrumbMerge.ts)). Клик по крошке **не меняет** отображаемый стек сразу: планируется усечение (`scheduleBreadcrumbTruncateAfterNavigation`), затем `router.push`; после смены URL усечение применяется **в начале** первого `applyForwardSeed` на целевой странице либо финальным слоем **`BreadcrumbPendingTruncateFlush`**, если на странице нет `BreadcrumbSeedPort`. Для простых экранов кабинета без общего префикса с предыдущим стеком **`AccountDefaultBreadcrumbSeed`** вызывает **`replaceTrailWithSeed`**. Дальше по смыслу сидов см. прежние правила веток `fromVacancy` и т.д. в [`navBreadcrumbTrail.ts`](../src/lib/navBreadcrumbTrail.ts).

## Формы

Клиентские формы в кабинете и жалобах используют **`FieldGroup` / `Field` / `FieldLabel`** из [`src/components/ui/field.tsx`](../src/components/ui/field.tsx), **`Input`**, **`Textarea`**, **`Select`**, **`Button`**, **`Alert`** — без вертикальных отступов через `space-y-*` (вместо них `flex flex-col gap-*` или встроенные зазоры `FieldGroup`).

## Модальные окна (Dialog)

Подтверждения и формы в модальных окнах на базе [`src/components/ui/dialog.tsx`](../src/components/ui/dialog.tsx): при **`pointer: fine`** рядом с кнопками «Отмена» / «Остаться» и основным действием показываются подсказки **Esc** / **⏎** (клавиша Enter) в [`DialogHotkeyKbd`](../src/components/ui/kbd.tsx); на устройствах с **грубым указателем** (`pointer: coarse`) эти подсказки скрыты. **Enter** вне полей ввода активирует основную кнопку (атрибут **`data-dialog-hotkey="confirm"`**); **Escape** закрывает диалог (Radix). При **`actionHotkeys`** автофокус при открытии переводится на основную кнопку (**`onOpenAutoFocus`** Radix: `preventDefault` + фокус на `data-dialog-hotkey="confirm"`), если в контенте **нет** поля ввода вне футера; иначе остаётся стандартное поведение (в т.ч. диалог **«Сохранить фильтр»** — фокус в поле имени). В диалоге с текстовым полем **Enter** в поле сохраняет нативное поведение отправки формы.

Панель фильтров каталога рефералок ([`src/app/vacancies/VacancyFilters.tsx`](../src/app/vacancies/VacancyFilters.tsx)) на ширине **от `md`** — **липкий сайдбар** (`aside` в [`VacancyCatalogClient.tsx`](../src/app/vacancies/VacancyCatalogClient.tsx)); **до `md`** в потоке страницы **не показывается**: те же фильтры открываются **`Sheet` снизу** по **плавающей кнопке** (`@tabler/icons-react`: **IconFilter**, если нет полей пресета каталога, **IconFilterFilled** при ненулевых полях пресета — по **`vacancyCatalogHasPresetSaveFields`** в [`vacancyListQuery.ts`](../src/lib/vacancyListQuery.ts), **без учёта страницы пагинации**; полный сброс и кнопка **«Сбросить»** у сохранённых наборов по-прежнему опираются на **`isVacancyCatalogFlatBaseline`**) в том же клиенте каталога; в **`SheetContent`** корневым контейнером служит **`Card`**; заголовок панели — **`SheetTitle`**, нижняя зона футера карточки фильтров — **`SheetFooter`** / на десктопе **`CardFooter`**: верхний ряд — круглый сброс (**RotateCcw**) и либо **иконка сохранения набора** (**Save**, подсказка «Сохранить фильтр»), если сохранённый пресет не выбран и есть хотя бы одно пресет-поле: диалог именования и **`vacancySearchPresets.create`** у авторизованного / переход гостя на логин (**перед** переходом гостя **Sheet** закрывается через **`onApplyFilters`**); на **`md`** и выше — прокрутка к основной колонке с **`data-vacancy-catalog-main`**; пока открыт диалог сохранения или дубликата, **Sheet не закрывают** при нажатии на иконку — иначе содержимое фильтров размонтируется вместе с диалогом; после **успешного** **`vacancySearchPresets.create`** или после подтверждённого **`vacancySearchPresets.delete`** мобильный **`Sheet`** закрывается тем же **`onApplyFilters`**. Либо при выбранном пресете — **справа** компактная круглая кнопка-триггер **`DropdownMenu`** (иконка вертикального меню): пункт **«Дублировать»** с иконкой копирования — открывает диалог именования нового набора (как иконка **Save** при отсутствии выбранного пресета), по умолчанию имя «… (копия)», в **`vacancySearchPresets.create`** передаются **параметры выбранного сохранённого пресета**, а не текущее состояние каталога); **разделитель** (**`DropdownMenuSeparator`**); пункт **«Удалить»** (destructive; подтверждение в диалоге); у **`SheetFooter`** (`mt-auto`, **safe-area** снизу); прокручивается только **`CardContent`**. **Блок «Сохранённые фильтры»** (заголовок **`h2`** как у «Ваша рефералка» в [`EmployerHomeVacancySection.tsx`](../src/app/vacancies/EmployerHomeVacancySection.tsx) — `text-lg font-semibold`, с **IconBookmarksFilled** (Tabler) и **`ToggleGroup`** в [`VacancySavedPresetsCarousel.tsx`](../src/app/vacancies/VacancySavedPresetsCarousel.tsx); у каждого пункта **`Tooltip`**: активный — «Выбранный фильтр», остальные — «Нажми чтобы применить фильтр»; у выбранного пункта слева иконка **IconCircleDotFilled** (Tabler) как знак применённого набора; триггер не сидит напрямую на **`ToggleGroupItem`**, чтобы не перезаписывать **`data-state`** переключателя атрибутами тултипа; справа в одной строке с заголовком — кнопка **«Сбросить»** в варианте **link** с **Tooltip** «Сбросить фильтры» (**не рендерится**, пока для текущего состояния каталога истинно **`isVacancyCatalogFlatBaseline`** в [`vacancyListQuery.ts`](../src/lib/vacancyListQuery.ts)); тот же сброс каталога и пресета, что и **RotateCcw** в панели фильтров) показывается **только авторизованному** пользователю **и только если есть хотя бы один сохранённый набор** в основной колонке [`VacancyCatalogClient.tsx`](../src/app/vacancies/VacancyCatalogClient.tsx) **над** строкой поиска ([`VacancyListChrome.tsx`](../src/app/vacancies/VacancyListChrome.tsx)); между блоком [`EmployerHomeVacancySection.tsx`](../src/app/vacancies/EmployerHomeVacancySection.tsx) и группой пресетов/поиском/лентой каталога — горизонтальный **`Separator`** ([`src/components/ui/separator.tsx`](../src/components/ui/separator.tsx)). Иконка **«Сохранить фильтр»** доступна и гостю: по нажатию — переход на [`/login`](../src/app/login/page.tsx) с **`callbackUrl`** на каталог, в строке запроса — флаг **`openVacancyPresetSave=1`** и текущие параметры фильтра; после OAuth диалог сохранения пресета открывается автоматически, служебный флаг с URL снимается. Повторный клик по активному пункту группы снимает выбор (**сброс параметров каталога** и привязки к пресету). Далее в сайдбаре / **`Sheet`**: при выбранном сохранённом пресете над специализацией — редактируемое поле **«Название фильтра»** (до 80 символов); при **первом сохранении** нового набора (диалог **«Сохранить фильтр»**, в т.ч. после OAuth) поле имени изначально **пустое** (автоматический эмодзи-префикс **не** подставляется — пользователь вводит название сам, в т.ч. может добавить эмодзи вручную); при открытии этого диалога значение в поле имени **не** выделяется целиком — каретка в конце строки; при **«Дублировать»** по умолчанию имя вида «… (копия)»; сохранение через **`vacancySearchPresets.update`** при потере фокуса, пустое значение не допускается — поле возвращается к последнему сохранённому названию); выбор **специализации** — одиночный **`Select`** (значение «Любая» снимает фильтр по специализации); грейд и формат работы — группы переключателей; блок **«Зарплата не ниже»** — единый **`InputGroup`**: числовой ввод и компактный выбор валюты (**`DropdownMenu`**, радиопункты RUB / USD / EUR; в виджете по умолчанию RUB; **при пустой сумме** в параметрах каталога не задаются ни `salaryFrom`, ни `salaryCurrency` — без сужения по сумме и по валюте; валюта применяется только вместе с указанным минимумом); в сохранённом пресете и при сравнении с пресетом **`salaryCurrency` не хранится и не участвует**, если нет **`salaryFrom`**; у **`SelectContent`** специализации задано **`position="popper"`**. Состояние фильтров и поиска живёт в клиентском каталоге; при изменении фильтров **строка адреса не обновляется**. В **режиме сайдбара** карточка фильтров **остаётся смонтированной** при смене параметров (блок зарплаты — отдельный `key` по закоммиченным `salaryFrom` и `salaryCurrency` из `currentParams`, без эффекта синхронизации). Идентификатор выбранного **сохранённого пресета** (для активного выбора в группе пресетов и режима сохранения пресета в футере фильтров) держится в состоянии каталога и не сбрасывается при расхождении текущих полей со снимком пресета, пока пользователь не снимет выбор сохранённого пресета (повторный клик по активному пункту группы, круглый сброс фильтров или явный переход к другому пресету) или не сменит активный пресет. Круглая кнопка **сброса фильтров** (RotateCcw) сбрасывает параметры каталога **и** снимает выбор сохранённого пресета (флаг в каталоге плюс перемонтирование блока группы пресетов по счётчику). При активном выбранном пресете параметры фильтра каталога (включая сортировку и строку поиска из основной колонки после подтверждения поиска), которые входят в сохранённый набор, **автоматически синхронизируются** с сервером через **`vacancySearchPresets.update`** после изменения (debounce); показывается тост об успешном сохранении параметров; имя пресета сохраняется при **`blur`** поля «Название фильтра». Новый именованный набор без выбранного пресета — иконка **Save** рядом со сбросом (диалог и **`vacancySearchPresets.create`** из текущего каталога); после успешного сохранения этот набор **автоматически выбирается** как активный сохранённый пресет (группа пресетов и футер фильтров); копия сохранённого набора по параметрам из БД — пункт **«Дублировать»** в **`DropdownMenu`** при выбранном пресете. Для полей с несколькими значениями через запятую сравнение по **набору** допустимых значений, порядок токенов в строке не влияет. При смене номера страницы пагинации в [`VacancyCatalogClient.tsx`](../src/app/vacancies/VacancyCatalogClient.tsx) выполняется **`scrollIntoView`** контейнера с **`data-vacancy-catalog-main`** (`behavior: "smooth"`, `block: "start"`), чтобы основная колонка с лентой оказалась у верха области просмотра. Первый запрос страницы по-прежнему может использовать `searchParams` на сервере только для начальной гидратации. Внутреннее представление специализации (и в сохранённых пресетах) по-прежнему может быть строкой с несколькими значениями через запятую; при нескольких значениях в списке показывается служебный пункт до выбора одной специализации или «Любая». В [`VacancyListChrome.tsx`](../src/app/vacancies/VacancyListChrome.tsx) у **`Select`** сортировки пункты с иконками **Tabler** (`@tabler/icons-react`), у **`SelectContent`** задано **`position="popper"`**; справа в той же строке сводка числа рефералок с **`Tooltip`** «Найденное количество рефералок».
