# UI shell (навигация и страницы)

Нормативное описание оболочки интерфейса после выравнивания с публичным каталогом вакансий.

## Компоненты шапки

| Область | Компонент | Файл |
|--------|-----------|------|
| Публичные страницы (каталог, деталь вакансии, login, регистрация, mock-оплата, pay без вложенного layout) | `PublicHeaderNav` | [`src/components/PublicHeaderNav.tsx`](../src/components/PublicHeaderNav.tsx) |
| Кабинет `/dashboard/*` | `DashboardHeaderNav` + layout | [`src/components/DashboardHeaderNav.tsx`](../src/components/DashboardHeaderNav.tsx), [`src/app/dashboard/layout.tsx`](../src/app/dashboard/layout.tsx) |
| Модерация `/admin/*` | `AdminHeaderNav` + layout | [`src/components/AdminHeaderNav.tsx`](../src/components/AdminHeaderNav.tsx), [`src/app/admin/layout.tsx`](../src/app/admin/layout.tsx) |

Правило: **первичная навигация задаётся в `layout.tsx` соответствующего сегмента**, а не дублируется в каждой `page.tsx`. Ссылка бренда слева (квадрат с «R» и текст **Referi**) во всех трёх шапках показывает **и логотип, и название** на всех ширинах viewport (без скрытия текста на узких экранах); переход в **каталог вакансий** — по этой ссылке на главную (`/`). Отдельного выпадающего меню «Вакансии» в шапке нет. В шапках кабинета и админки доступны переключатель темы (`ThemeToggle`) и выход из аккаунта (через меню профиля). Аватар в шапке: фото профиля GitHub (`session.user.image` / запасной URL по логину), при отсутствии или ошибке загрузки — инициалы в `AvatarFallback`.

## Поверхность страницы и токены

Фон «страницы приложения» (в т.ч. каталог и кабинет) задаётся CSS-переменной **`--app-page-surface`** в [`src/app/globals.css`](../src/app/globals.css). Акцент поиска в шапке: **`--app-search-accent-*`**. Токены **`--app-nav-cta-*`** используются в панели фильтров каталога (в т.ч. сегментированные кнопки пресетов), не в шапке.

Тема: `next-themes` в корневом [`src/app/layout.tsx`](../src/app/layout.tsx); семантические классы Tailwind (`bg-background`, `text-muted-foreground`, `border-border`, компоненты shadcn) предпочтительнее сырых `gray-*`.

## Формы

Клиентские формы в кабинете и жалобах используют **`FieldGroup` / `Field` / `FieldLabel`** из [`src/components/ui/field.tsx`](../src/components/ui/field.tsx), **`Input`**, **`Textarea`**, **`Select`**, **`Button`**, **`Alert`** — без вертикальных отступов через `space-y-*` (вместо них `flex flex-col gap-*` или встроенные зазоры `FieldGroup`).

Панель фильтров каталога вакансий ([`src/app/vacancies/VacancyFilters.tsx`](../src/app/vacancies/VacancyFilters.tsx)) на ширине **от `md`** — **липкий сайдбар** (`aside` в [`VacancyCatalogClient.tsx`](../src/app/vacancies/VacancyCatalogClient.tsx)); **до `md`** в потоке страницы **не показывается**: те же фильтры открываются **`Sheet` снизу** по **плавающей кнопке** в том же клиенте каталога; в **`SheetContent`** корневым контейнером служит **`Card`**; заголовок панели — **`SheetTitle`**, нижняя зона (сброс и действия с пресетами) — **`SheetFooter`** (`mt-auto`, **safe-area** снизу); прокручивается только **`CardContent`**. Блок **«Ваши фильтры»** (вкладки сохранённых пресетов) показывается **только авторизованному** пользователю. Кнопка **«Сохранить»** доступна и гостю: по нажатию — переход на [`/login`](../src/app/login/page.tsx) с **`callbackUrl`** на каталог, в строке запроса — флаг **`openVacancyPresetSave=1`** и текущие параметры фильтра; после OAuth диалог сохранения пресета открывается автоматически, служебный флаг с URL снимается. Сохранённые наборы (**пресеты**) для авторизованного пользователя выбираются горизонтальным рядом вкладок **`Tabs`** ([`src/components/ui/tabs.tsx`](../src/components/ui/tabs.tsx)): вкладка **«Не выбран»** (то же действие, что прежний пункт «Очистить выбор» — сброс параметров каталога и снятие привязки к пресету) и по одной вкладке на каждый сохранённый набор; ряд вкладок с **горизонтальной прокруткой**. Далее в столбце без вкладок: выбор **специализации** — одиночный **`Select`** (значение «Любая» снимает фильтр по специализации); грейд и формат работы — группы переключателей; блок **«Зарплата не ниже»** — единый **`InputGroup`**: числовой ввод и компактный выбор валюты (**`DropdownMenu`**, радиопункты RUB / USD / EUR; в виджете по умолчанию RUB; **при пустой сумме** в параметрах каталога не задаются ни `salaryFrom`, ни `salaryCurrency` — без сужения по сумме и по валюте; валюта применяется только вместе с указанным минимумом); в сохранённом пресете и при сравнении с пресетом **`salaryCurrency` не хранится и не участвует**, если нет **`salaryFrom`**; у **`SelectContent`** специализации задано **`position="popper"`**. Состояние фильтров и поиска живёт в клиентском каталоге; при изменении фильтров **строка адреса не обновляется**. В **режиме сайдбара** карточка фильтров **остаётся смонтированной** при смене параметров (блок зарплаты — отдельный `key` по закоммиченным `salaryFrom` и `salaryCurrency` из `currentParams`, без эффекта синхронизации). Идентификатор выбранного в панели фильтров **сохранённого пресета** (для активной вкладки пресета и режима «Обновить») держится в состоянии каталога и не сбрасывается при расхождении текущих полей со снимком пресета, пока пользователь не перейдёт на «Не выбран» или не сменит пресет. Круглая кнопка **сброса фильтров** (RotateCcw) сбрасывает параметры каталога **и** снимает выбор пресета до вкладки **«Не выбран»** (флаг в каталоге плюс перемонтирование блока вкладок пресетов по счётчику — иначе Radix может оставить прежнюю активную вкладку при смене `value`). Пока набор полей пресета (специализация, грейд, формат, валюта зарплаты, зарплата, сортировка, строка поиска) **совпадает** со снимком выбранного пресета, вместо «Обновить» и меню действий показывается одна кнопка **«Удалить»** (`variant="destructive"`). После **любого расхождения** снова показываются **«Обновить»** и выпадающее меню (создание нового пресета, удаление). Для полей с несколькими значениями через запятую сравнение по **набору** допустимых значений, порядок токенов в строке не влияет. Первый запрос страницы по-прежнему может использовать `searchParams` на сервере только для начальной гидратации. Внутреннее представление специализации (и в сохранённых пресетах) по-прежнему может быть строкой с несколькими значениями через запятую; при нескольких значениях в списке показывается служебный пункт до выбора одной специализации или «Любая». В [`VacancyListChrome.tsx`](../src/app/vacancies/VacancyListChrome.tsx) у **`Select`** сортировки пункты с иконками **Tabler** (`@tabler/icons-react`), у **`SelectContent`** задано **`position="popper"`**.
